Import tips and timing

You do not need to ZIP the inputs. Choose multiple transcript files, or select a model-output folder (Chrome/Edge folder selection is supported). For a folder containing multiple run subfolders, the importer picks each folder's canonical transcript.txt (or the primary_transcript specified in run.json). If a folder has no canonical transcript, eligible peer transcript files are imported individually; raw/chunk sidecars are skipped unless used for timing. For transcript.txt plus transcript.srt/.vtt, captions and timing are paired automatically. In a model folder, a single unambiguous SRT/VTT can also be used as the transcript's timing/caption sidecar even if its basename differs. Subtitle captions use exact cue boundaries; word-level seek/highlighting times are estimated within each cue unless a more precise timed JSON/chunk sidecar exists. A saved session JSON restores branches and edits; older sessions are upgraded with the current equivalence and auto-collapse rules when loaded. Load its audio separately if you want playback. Edits stay in browser memory until you explicitly export a new JSON; the file you loaded is never updated automatically. Firefox may call folder selection an “upload”; that is a native confirmation to give this page access to read the selected files, not a transfer to a server.
